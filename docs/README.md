# daccord Documentation

End-user docs for the daccord client, consumed by external site generators. `index.md` is the home page; each subdirectory (`getting-started/`, `messaging/`, `navigation/`, `voice-and-video/`, `customization/`, `administration/`, `self-hosting/`, `troubleshooting/`) is a section.

## Conventions

- **Audience:** non-technical end users; second person, concise. No API or implementation detail.
- **Front matter:** `title` (nav and `<title>`), `description` (SEO/previews), `order` (sort within section), `section` (directory slug).
- **Headings:** H1 matching `title`, then H2/H3 only.
- **Links/images:** relative paths; images in an `images/` directory beside the page.
