# Themes and Appearance

Open **Settings** (the gear button in the space bar) and go to **App → Appearance**. Changes apply immediately.

- **Theme** -- Dark, Midnight, Light, Nord, Monokai, or Solarized
- **Accent colour** -- the default or one of the preset swatches
- **Compact mode** -- a denser message layout
- **Convert emoticons to emoji** -- turns `:)` and `<3` into emoji as you send
- **Reduced motion** -- minimises interface animations
- **UI scale** -- 80% to 140%

Animated images pause while daccord is in the background and resume when you return.
