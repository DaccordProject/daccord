# Invites

## Creating an Invite

1. Right-click the space icon and choose **Invite people**, or click the **Invite people** button at the top of the channel list.
2. Set the options:
   - **Expire after** -- 30 minutes, 1 hour, 1 day (default), 7 days, or Never.
   - **Max uses** -- No limit, or 1 to 100 uses.
   - **Temporary membership** -- people who join are removed when they disconnect unless they've been given a role.
3. Click **Create**, then copy the link to share it.

The same dialog lists active invites. Revoke one, or select several and revoke them together.

## Joining via Invite

A `daccord://` invite link opens daccord and connects automatically. For a server URL with an invite code, paste it into **Add a Server**; see [Adding a Server](../getting-started/adding-a-server.md).
